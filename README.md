# Android Project

## Installation
1. Cloner le projet
2. Ouvrir dans Android Studio
3. Synchroniser Gradle
4. Exécuter sur émulateur ou appareil

## Prérequis
- Android Studio compatible avec Android Gradle Plugin 8.1.1
- JDK 17
- SDK Android 34 (la version minimale prise en charge par l'application est Android 5.0 / API 21)
- Gradle 8.0+ pour lancer `setup.sh` si aucun wrapper Gradle n'est présent
